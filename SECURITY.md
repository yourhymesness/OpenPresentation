# Security

OpenPresentation is alpha software and has not undergone an independent security audit. Do not use it to open untrusted presentations or media in show-critical environments.

If you believe you have found a security vulnerability, **do not disclose exploit details publicly in an Issue**. Contact [william.hymes@hitechproductions.com](mailto:william.hymes@hitechproductions.com) with a concise report and reproduction steps. This is not a guaranteed response-time service.
